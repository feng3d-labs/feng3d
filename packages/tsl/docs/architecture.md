# 架构说明

## 系统架构

TSL 采用分层架构设计，从底层类型系统到高层着色器 API，各层职责清晰。

```
┌─────────────────────────────────────────────────────────┐
│                    用户代码层                           │
│         vertex/fragment/func + 变量 + 函数调用           │
└─────────────────────────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────┐
│                   着色器构建层                           │
│            buildShader + analyzeDependencies             │
└─────────────────────────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────┐
│                    代码生成层                           │
│              toWGSL() / toGLSL() 转换                    │
└─────────────────────────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────┐
│                    平台输出层                           │
│                  WGSL / GLSL 字符串                      │
└─────────────────────────────────────────────────────────┘
```

## 核心模块

### 1. 核心层 (core/)

**职责**：定义基础接口和构建逻辑

| 文件 | 职责 |
|------|------|
| `IElement.ts` | 定义 `ShaderValue` 和 `IElement` 接口，所有着色器值的基类 |
| `buildShader.ts` | 着色器构建器，管理构建上下文 |
| `analyzeDependencies.ts` | 依赖分析器，自动收集 attributes/uniforms/varyings |
| `Statement.ts` | 语句接口，支持可执行的着色器语句 |
| `currentFunc.ts` | 当前函数上下文管理 |
| `ifStack.ts` | 条件语句堆栈 |
| `expressionUtils.ts` | 表达式工具函数 |
| `formatNumber.ts` | 数字格式化 |

### 2. 变量层 (variables/)

**职责**：管理各类着色器变量的声明和绑定

| 文件 | 职责 |
|------|------|
| `attribute.ts` | 顶点属性，自动分配 location |
| `uniform.ts` | 全局变量，自动分配 binding |
| `varying.ts` | 顶点到片段插值变量 |
| `let.ts` | 局部变量（作用域在函数内） |
| `var.ts` | 全局变量（作用域在整个着色器） |
| `struct.ts` | 结构体定义 |
| `array.ts` | 数组类型 |

### 3. 类型层 (types/)

**职责**：定义着色器数据类型

```
types/
├── scalar/    # 标量: bool, float, int, uint
├── vector/    # 向量: vec2/3/4, ivec2/3/4, uvec2/3/4, bvec3
└── matrix/    # 矩阵: mat2, mat4, mat4x3
```

### 4. 着色器层 (shader/)

**职责**：定义着色器入口点

| 文件 | 职责 |
|------|------|
| `vertex.ts` | 顶点着色器入口 |
| `fragment.ts` | 片段着色器入口 |
| `transform.ts` | 变换着色器 |
| `func.ts` | 可重用函数 |

### 5. GLSL 层 (glsl/)

**职责**：GLSL/WGSL 特有功能

```
glsl/
├── builtin/      # 内置变量: gl_Position, gl_FragColor 等
├── sampler/      # 采样器类型
├── texture/      # 纹理采样函数
└── derivative/   # 导数函数: dFdx, dFdy
```

### 6. 数学层 (math/)

**职责**：数学计算函数

```
math/
├── common/       # 通用: clamp, mix, step, smoothstep
├── exponential/  # 指数: exp, log2, pow, sqrt
└── trigonometric/# 三角: sin, cos, atan, acos
```

### 7. 控制层 (control/)

**职责**：控制流语句

| 文件 | 职责 |
|------|------|
| `if_.ts` | 条件语句 |
| `select.ts` | 三元选择 |
| `return.ts` | 返回语句 |

### 8. 向量层 (vector/)

**职责**：向量数学运算

| 文件 | 职责 |
|------|------|
| `dot.ts` | 点积 |
| `cross.ts` | 叉积 |
| `normalize.ts` | 归一化 |
| `reflect.ts` | 反射 |
| `lessThan.ts` | 小于比较 |

## 代码生成流程

```
用户代码
    │
    ▼
┌───────────────────────────────────┐
│  1. 构建阶段                      │
│  - buildShader() 设置上下文       │
│  - 创建着色器入口 (vertex/fragment)│
│  - 执行着色器函数体               │
└───────────────────────────────────┘
    │
    ▼
┌───────────────────────────────────┐
│  2. 依赖收集阶段                  │
│  - 遍历 ShaderValue 树            │
│  - 收集 attributes/uniforms        │
│  - 分配 location/binding          │
│  - 分析 struct 定义               │
└───────────────────────────────────┘
    │
    ▼
┌───────────────────────────────────┐
│  3. 代码生成阶段                  │
│  - 遍历所有元素                   │
│  - 调用 toWGSL() / toGLSL()        │
│  - 处理平台差异                   │
│  - 生成最终着色器代码             │
└───────────────────────────────────┘
    │
    ▼
WGSL / GLSL 字符串
```

## 依赖关系图

```
                    core/IElement
                           │
        ┌──────────────────┼──────────────────┐
        │                  │                  │
    variables           types              shader
        │                  │                  │
        │         ┌───────┴───────┐          │
        │         │              │          │
      glsl      math          vector       control
```

## 设计原则

1. **类型安全优先** - 所有 API 都有完整的类型定义
2. **链式友好** - 支持流畅的链式调用
3. **自动推断** - 自动处理依赖和资源分配
4. **平台抽象** - 屏蔽 GLSL/WGSL 差异
5. **渐进增强** - 从简单示例到复杂用例都能支持
