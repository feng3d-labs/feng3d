# 编辑器门禁与自检清单

> 状态：**现行规范**。`packages/editor` 的门禁 / 自检脚本全表。
>
> **为什么单独放这里**：这份清单是**按需查阅的 reference**（改完某块代码才来查"该跑哪条"），
> 不是每轮都需要的指令——留在 [AGENTS.md](../AGENTS.md) 里会让它每轮常驻 180 余行。
> "你改了什么 → 跑这个"的速查表在 [AGENTS.md](../AGENTS.md) 的「其它自检」一节。

**共性**：脚本自带判据与自证，失败即 `exit 1`。已进 CI 的由 `gates:host` / `editor-e2e` job 执行，
本地不必手动跑（`check-verifier-wiring.mjs` 守着"写了门禁必须有人跑"）。
性能基线类脚本是**决策依据而非门禁**（耗时受机器影响，做成门禁只会让 CI 变脆），只在做取舍时跑。
