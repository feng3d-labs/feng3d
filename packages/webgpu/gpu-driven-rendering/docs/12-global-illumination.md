## 概述

全局光照（Global Illumination，简称GI）模拟光线在场景中的多次反弹，产生真实的间接光照、颜色溢出和软阴影效果。本系统提供多种GI技术选择，平衡质量和性能。

### 什么是全局光照

传统渲染只计算光源直接照射到物体的光照（直接光照）。全局光照额外考虑：
- **间接光照**：光线在物体间反弹产生的光照
- **颜色溢出**：有色物体表面反射光线影响邻近物体
- **软阴影**：部分遮挡产生的柔和阴影

### 设计目标

- **多种技术**：提供从简单到复杂的多种GI方案
- **可配置**：根据场景和硬件选择合适的技术
- **GPU加速**：充分利用GPU并行计算能力
- **渐进式**：支持渐进式提高质量

## SSAO（屏幕空间环境光遮蔽）

### 原理

在屏幕空间采样周围像素的深度，判断当前像素是否被周围几何体遮挡，模拟环境光遮蔽效果。

### 效果

- 在角落、缝隙处产生阴影
- 增强物体接触感
- 提升场景立体感

### 优点

- 完全基于屏幕空间
- 性能开销小
- 不需要预计算
- 支持动态场景

### 缺点

- 只能处理屏幕可见的遮挡
- 可能产生噪点
- 质量受采样数限制

### 参数

| 参数 | 说明 | 范围 |
|------|------|------|
| Radius | 采样半径 | 0.1 - 2.0 |
| Bias | 深度偏移 | 0.001 - 0.1 |
| Samples | 采样数量 | 8 - 64 |
| Intensity | 遮蔽强度 | 0.5 - 3.0 |

### 应用场景

- 实时游戏
- 性能敏感场景
- 快速原型开发

---

## SSGI（屏幕空间全局光照）

### 原理

通过屏幕空间反射（SSR）技术追踪光线在屏幕可见表面的反弹，计算间接光照。

### 效果

- 真实的间接光照
- 颜色溢出效果
- 光滑表面反射

### 优点

- 比SSAO更真实
- 支持颜色溢出
- 动态场景

### 缺点

- 只能处理屏幕可见的间接光
- 性能开销较大
- 可能产生伪影

### 参数

| 参数 | 说明 | 范围 |
|------|------|------|
| Steps | 光线步进数 | 8 - 64 |
| RayLength | 光线最大长度 | 1 - 100 |
| Intensity | 间接光照强度 | 0.1 - 2.0 |
| Bounces | 反弹次数 | 1 - 3 |

### 应用场景

- 高质量实时渲染
- 室内场景
- 需要颜色溢出的场景

## Light Probes（光照探针）

### 原理

在场景中放置探针点，预计算或实时采样每个探针位置的光照信息，运行时对物体进行插值。

### 探针类型

| 类型 | 说明 | 更新方式 |
|------|------|----------|
| **Spherical Harmonics** | 球谐函数，低频光照 | 实时/烘焙 |
| **Cube Map** | 立方体贴图，高频光照 | 烘焙 |
| **Irradiance Volume** | 照度体积，混合方案 | 渐进式 |

### 探针布局

```
规则网格布局：
┌─────────────────────────────────────────────────────────────┐
│                                                              │
│      ◉      ◉      ◉      ◉      ◉                         │
│                                                              │
│      ◉      ◉      ◉      ◉      ◉                         │
│                                                              │
│      ◉      ◉      ◉      ◉      ◉                         │
│                                                              │
│      ◉      ◉      ◉      ◉      ◉                         │
│                                                              │
│  探针间距：2-10米（根据场景密度调整）                          │
│  球谐阶数：2-3阶（9-16系数）                                  │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### 优点

- 性能开销小
- 支持动态光照
- 适合室内场景

### 缺点

- 需要预布置探针
- 间接光精度有限
- 大场景探针数量多

### 应用场景

- 室内游戏场景
- 建筑可视化
- 需要快速烘焙的场景

## LPV（光传播体积）

### 原理

将场景光照信息注入3D网格中，通过传播算法模拟光线在体积中的扩散。

### 流程

```
┌─────────────────────────────────────────────────────────────┐
│                    LPV 渲染流程                              │
├─────────────────────────────────────────────────────────────┤
│  1. RSM（Reflective Shadow Map）生成                         │
│     ├── 世界坐标                                             │
│     ├── 法线                                                 │
│     └── 通量                                                 │
│  2. 光照注入              （将光源信息注入3D网格）             │
│  3. 光照传播              （多次迭代传播）                    │
│  4. 间接光照渲染          （读取体积数据）                    │
└─────────────────────────────────────────────────────────────┘
```

### 优点

- 真实的间接光照
- 支持动态光源
- 颜色溢出自然

### 缺点

- 内存占用大
- 实现复杂
- 可能产生光泄漏

### 参数

| 参数 | 说明 | 范围 |
|------|------|------|
| Grid Resolution | 3D网格分辨率 | 32³ - 128³ |
| Propagation Steps | 传播迭代次数 | 2 - 8 |
| Inject Intensity | 注入强度 | 0.5 - 2.0 |

### 应用场景

- 大型开放世界
- 多动态光源场景
- 需要高质量GI的游戏

## Voxel GI（体积GI）

### 原理

将场景体素化，在每个体素中存储光照信息，使用锥追踪（Voxel Cone Tracing）计算间接光照。

### 流程

```
┌─────────────────────────────────────────────────────────────┐
│                   Voxel GI 流程                              │
├─────────────────────────────────────────────────────────────┤
│  1. 场景体素化            （几何转换为3D纹理）                 │
│  2. 体素光照注入          （计算直接光照）                     │
│  3. 体素传播              （模拟光线反弹）                     │
│  4. 锥追踪               （从视角采样体素数据）                │
└─────────────────────────────────────────────────────────────┘
```

### 优点

- 极高质量的间接光照
- 全局效果一致
- 支持软阴影

### 缺点

- 体素化开销大
- 内存占用极高
- 静态场景为主

### 参数

| 参数 | 说明 | 范围 |
|------|------|------|
| Voxel Resolution | 体素分辨率 | 128³ - 512³ |
| Cone Count | 追踪锥数量 | 4 - 16 |
| Mip Levels | Mipmap层级 | 4 - 8 |

### 应用场景

- 静态高质量场景
- 建筑预渲染
- 电影级渲染

---

## Ray Traced GI（光线追踪GI）

### 原理

使用硬件光线追踪实时计算间接光照，通过采样多条路径估计辐照度。

### 技术

| 技术 | 说明 | 采样数 |
|------|------|--------|
| **Path Tracing** | 路径追踪，无偏估计 | 256+ |
| **Bidirectional** | 双向路径追踪 | 128+ |
| **Instant GI** | 即时GI，单帧 | 1 |

### 优点

- 物理准确的间接光照
- 无预计算
- 支持完全动态场景

### 缺点

- 需要RTX硬件
- 性能开销大
- 需要降噪

### 应用场景

- 高端PC游戏
- 实时建筑可视化
- 光线追踪演示

---

## 降噪技术

### 为什么需要降噪

实时GI由于采样数有限，会产生噪点。降噪技术可以从少量样本重建干净图像。

### 技术

| 技术 | 类型 | 延迟 | 质量 |
|------|------|------|------|
| **Spatial** | 空域滤波 | 低 | 中 |
| **Temporal** | 时域累积 | 中 | 高 |
| **SVGF** | 稀疏采样 | 中 | 极高 |
| **AI Denoiser** | 神经网络 | 高 | 极高 |

## 混合方案

### 多层级GI

根据场景区域使用不同技术：

```
近处角色：Light Probes（高质量）
室内场景：SSGI + Light Probes
室外开放：LPV + Light Probes
静态背景：Voxel GI（预计算）
```

### 动态调整

根据帧率动态调整GI质量：

- 高帧率：降低GI质量
- 低帧率：提高GI质量
- 静止时：渐进式提高质量

### 场景类型推荐

| 硬件 | 推荐配置 |
|------|----------|
| 移动端 | SSAO |
| 中端PC | SSAO + Light Probes |
| 高端PC | SSGI + LPV |
| RTX显卡 | Ray Traced GI |
