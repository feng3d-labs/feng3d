## 粒子系统

### 原理

粒子系统通过大量小型图像（粒子）模拟火焰、烟雾、火花、魔法效果等。

### 粒子生命周期

```
┌─────────────────────────────────────────────────────────────┐
│                    粒子生命周期                               │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  发射 → 更新 → 渲染 → 死亡                                    │
│   ↑      │      │      │                                    │
│   └──────┴──────┴──────┘                                    │
│         循环（循环粒子系统）                                   │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### GPU粒子系统

传统粒子系统在CPU上更新，GPU粒子系统将所有计算移至GPU。

#### 数据结构

```
粒子属性（存储在Structured Buffer）：
- Position (vec3)
- Velocity (vec3)
- Color (vec4)
- Size (float)
- Life (float)
- Type (uint)
```

#### 计算着色器更新

```
计算着色器任务：
1. 读取粒子当前状态
2. 应用物理模拟（重力、风力、阻力）
3. 更新位置和速度
4. 检查生命周期
5. 写入新状态（Double Buffering）
```

#### 间接绘制

使用GPU生成的绘制命令渲染粒子：
- 死亡粒子不生成绘制命令
- 按粒子类型分组绘制
- 支持数万粒子同时渲染

### 粒子类型

| 类型 | 渲染方式 | 应用 |
|------|----------|------|
| **Billboard** | 始终面向相机 | 烟雾、火花 |
| **Stretched** | 沿速度方向拉伸 | 雨滴、魔法束 |
| **Mesh** | 3D网格模型 | 碎片、树叶 |
| **Trail** | 轨迹渲染 | 拖尾效果 |

### 发射器类型

| 类型 | 说明 |
|------|------|
| **Point** | 点发射，向四周扩散 |
| **Directional** | 定向发射 |
| **Cone** | 锥形发射范围 |
| **Sphere** | 球形表面发射 |
| **Curve** | 沿曲线发射 |

### 优化策略

- **视锥剔除**：剔除屏幕外粒子
- **LOD**：远处粒子降低更新频率
- **模拟空间分区**：只模拟活跃区域
- **GPU Sorting**：按深度排序透明粒子

## 体积光（God Rays）

### 原理

模拟阳光穿过大气或云层产生的光束效果。

### 实现方法

#### 光线 marching

```
从相机向光源方向步进：
1. 计算光线方向
2. 沿光线采样深度
3. 累积光照衰减
4. 叠加到最终图像
```

#### 屏幕空间方法

```
后处理方式：
1. 提取光源位置
2. 径向模糊产生光束
3. 深度测试遮挡
4. 叠加效果
```

### 参数

| 参数 | 说明 | 范围 |
|------|------|------|
| Density | 体积光密度 | 0.01 - 1.0 |
| Weight | 每次采样权重 | 0.1 - 1.0 |
| Decay | 光线衰减 | 0.9 - 0.99 |
| Samples | 采样次数 | 16 - 128 |

## 体积雾

### 原理

模拟雾气在3D空间中的分布，随距离和高度变化。

### 类型

| 类型 | 说明 | 性能 |
|------|------|------|
| **指数雾** | 简单距离衰减 | 极高 |
| **高度雾** | 考虑高度因素 | 高 |
| **体积雾** | 3D体积数据 | 中 |
| **体积光雾** | 雾 + 体积光 | 中低 |

### 体积雾3D纹理

```
3D体积存储雾密度：
- 分辨率：128³ 或 256³
- 更新方式：实时或预计算
- 采样：三线性插值
```

### 雾效果参数

| 参数 | 说明 |
|------|------|
| Density | 雾密度 |
| Height | 雾高度 |
| Height Falloff | 高度衰减 |
| Color | 雾颜色 |
| Wind Direction | 风向（动态雾） |

## 云渲染

### 云类型

| 类型 | 渲染方法 | 质量 |
|------|----------|------|
| **2D Cloud** | 平面贴图 | 低 |
| **Billboard Cloud** | 多层billboard | 中 |
| **Volumetric Cloud** | 体积渲染 | 极高 |

### 体积云渲染

#### 噪声生成

使用Worley或Perlin噪声生成云形状：
- 多层噪声叠加
- 不同频率和幅度
- 动态噪声偏移模拟流动

#### 光线 marching

```
渲染流程：
1. 构建云体积边界
2. 从相机向天空方向步进
3. 采样云密度噪声
4. 计算散射和吸收
5. 累积光照和阴影
```

#### 优化

- **Early Exit**：密度低于阈值时提前终止
- **LOD**：远处云使用低分辨率采样
- **Temporal Upscaling**：时域上采样降低分辨率

## 水面渲染

### 水面效果

| 效果 | 实现方法 |
|------|----------|
| **波浪** | 法线贴图动画 + 顶点位移 |
| **反射** | 平面反射或屏幕空间反射 |
| **折射** | 深度缓冲采样 + 折射偏移 |
| **菲涅尔** | 根据视角混合反射/折射 |
| **焦散** | 光线穿透水面的聚焦效果 |

### 渲染流程

```
水面渲染Pass：
1. 渲染反射图（反射相机或屏幕空间）
2. 渲染折射图（背景深度采样）
3. 水面几何渲染
   - 法线贴图（波浪）
   - 菲涅尔计算
   - 反射/折射混合
4. 焦散叠加（可选）
```

### 参数

| 参数 | 说明 |
|------|------|
| Wave Height | 波浪高度 |
| Wave Speed | 波浪速度 |
| Refraction Index | 折射率 |
| Foam Threshold | 泡沫阈值 |
| Water Color | 水体颜色 |

## 其他特效

### 屏幕空间反射（SSR）

在屏幕空间追踪反射，模拟光滑表面反射。

```
流程：
1. 识别光滑表面
2. 从反射视线方向步进
3. 采样深度缓冲查找交点
4. 采样颜色作为反射
```

### 次表面散射（SSS）

模拟光线穿透半透明材质的效果。

```
应用：
- 皮肤
- 蜡烛
- 大理石
- 植物叶片
```

### 全息效果

模拟全息投影的条纹和干扰效果。

```
技术：
- 扫描线效果
- 色差分离
- 透明度变化
- 全息噪声
```

### Rain / Snow

天气效果模拟。

```
雨：
- 粒子系统 + 拉伸billboard
- 地面涟漪（法线动画）
- 湿润表面反射增强

雪：
- 轻粒子系统
- 风力影响
- 地面积雪累积
```

## 性能建议

### 粒子系统

- 使用GPU更新而非CPU
- 视锥剔除和LOD
- 限制同时活跃粒子数
- 使用简单着色器

### 体积效果

- 降低分辨率
- 减少采样次数
- 使用Early Exit
- 时域复用

### 特效分层

```
必须：基础粒子
重要：体积雾、水面
可选：体积光、高级云
高配：SSR、次表面散射
```
