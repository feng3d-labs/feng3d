## 概述

高级渲染技术包括硬件光线追踪和体素渲染，代表实时渲染的最前沿技术。这些技术能够实现电影级的视觉效果，但需要强大的硬件支持。

### 设计目标

- **电影级质量**：接近离线渲染的视觉效果
- **硬件加速**：充分利用现代GPU硬件特性
- **混合渲染**：与光栅化渲染无缝结合
- **可扩展**：支持从低端到高端的多种配置

## 硬件光线追踪

### 什么是光线追踪

光线追踪是一种渲染技术，通过模拟光线在场景中的传播来生成图像。与光栅化相比，它能更准确地模拟反射、折射、阴影和全局光照。

### WebGPU光线追踪

WebGPU支持通过Ray Tracing扩展进行硬件加速的光线追踪。

#### 核心概念

| 概念 | 说明 |
|------|------|
| **Ray Generation** | 生成追踪光线的着色器 |
| **Intersection** | 检测光线与几何体相交 |
| **Any Hit** | 检测相交的回调 |
| **Closest Hit** | 最近相交点的处理 |
| **Miss** | 光线未击中任何物体 |
| **Acceleration Structure** | 加速遍历的层级结构 |

#### 加速结构（AS）

```
┌─────────────────────────────────────────────────────────────┐
│                   加速结构层级                                │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  TLAS (Top-Level Acceleration Structure)                     │
│  ├── Instance 1 → BLAS (模型A)                               │
│  ├── Instance 2 → BLAS (模型B)                               │
│  └── Instance 3 → BLAS (模型C)                               │
│                                                              │
│  BLAS (Bottom-Level Acceleration Structure)                  │
│  ├── Triangle 1                                              │
│  ├── Triangle 2                                              │
│  └── ...                                                     │
│                                                              │
│  TLAS：实例层级，支持实例变换                                 │
│  BLAS：几何层级，优化三角形遍历                               │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### 光线追踪效果

#### 反射（Reflection）

模拟光滑表面的镜面反射。

```
流程：
1. 从相机发射主光线
2. 击中表面后发射反射光线
3. 递归追踪（通常1-3次）
4. 累积反射颜色
```

#### 折射（Refraction）

模拟光线穿过透明介质的效果。

```
应用：
- 玻璃
- 水
- 宝石
- 透明塑料
```

#### 软阴影（Soft Shadows）

使用面积光源产生柔和阴影。

```
技术：
- 多采样面积光源
- 自适应采样
- 降噪处理
```

#### 全局光照（Global Illumination）

通过路径追踪计算间接光照。

```
流程：
1. 发射主光线击中表面
2. 在表面半球随机采样方向
3. 递归追踪bounce
4. 累积光照贡献
```

### 混合渲染

光线追踪与传统光栅化结合：

```
混合渲染流程：
┌─────────────────────────────────────────────────────────────┐
│  1. G-Buffer / Z-PrePass         （光栅化）                   │
│  2. 光线追踪Pass                  （反射/阴影/GI）             │
│  3. 光栅化主渲染                  （不透明物体）                │
│  4. 透明物体前向渲染              （光栅化）                    │
│  5. 后处理                                                        │
└─────────────────────────────────────────────────────────────┘
```

### 性能优化

#### 降噪

实时路径追踪采样数有限，需要降噪：

| 技术 | 说明 |
|------|------|
| **Temporal Accumulation** | 时域累积 |
| **Spatial Filtering** | 空域滤波 |
| **SVGF** | 稀疏采样引导滤波 |
| **AI Denoising** | 神经网络降噪 |

#### 采样策略

```
自适应采样：
- 高频区域增加采样
- 低频区域减少采样
- 梯度分析指导采样分配
```

#### 复用

```
时域复用：
- 复用历史帧的光线
- 重投影技术
- 有效性检查
```

### 应用场景

| 场景 | 效果 | 采样数 |
|------|------|--------|
| 游戏 | 反射 + 阴影 | 1-4 |
| 建筑 | GI + 反射 | 16-64 |
| 电影 | 路径追踪 | 256+ |

## 体素渲染

### 什么是体素渲染

体素（Voxel）是"体积像素"（Volume Pixel）的缩写。体素渲染将场景离散化为3D网格，每个网格单元存储颜色、不透明度等属性。

### 体素化

将几何场景转换为体素表示。

```
体素化方法：
┌─────────────────────────────────────────────────────────────┐
│  1. 光线投射体素化                                            │
│     ├── 从多个方向投射光线                                   │
│     ├── 检测几何体相交                                       │
│     └── 标记占据的体素                                       │
│                                                              │
│  2. 硬件体素化                                               │
│     ├── 利用Geometry Shader                                  │
│     ├── 或利用Rasterization                                  │
│     └── 直接写入3D纹理                                       │
│                                                              │
│  3. 计算着色器体素化                                         │
│     ├── 原子操作标记                                         │
│     ├── 并行处理                                             │
│     └── 八叉树结构                                           │
└─────────────────────────────────────────────────────────────┘
```

### 体素数据结构

#### 稀疏体素八叉树（SVO）

```
八叉树结构：
根节点 (整个场景)
├── 子节点1 (1/8空间)
│   ├── 叶子节点 (体素数据)
│   └── ...
├── 子节点2 (1/8空间)
│   └── ...
└── ...

优势：
- 内存效率高
- 快速遍历
- LOD支持
```

#### 纹理3D

```
规则3D纹理：
- 简单直接
- 硬件采样优化
- 内存占用大
- 适合小场景
```

### 体素锥追踪（Voxel Cone Tracing）

一种高效的间接光照方法。

```
流程：
1. 场景体素化
2. 将光照注入体素
3. 从表面发射追踪锥
4. 沿锥采样体素数据
5. 计算间接光照
```

#### 追踪锥

```
锥配置：
┌─────────────────────────────────────────────────────────────┐
│                                                              │
│                    表面                                      │
│                        ◆  ← 锥的顶点                         │
│                       ╱│╲                                   │
│                      ╱ │ ╲                                  │
│                     ╱  │  ╲                                 │
│                    ╱   │   ╲                                │
│                   ╱    │    ╲                               │
│                                                              │
│  锥数量：4-16个                                               │
│  锥角度：逐步扩大                                             │
│  步进：沿锥方向采样体素                                       │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### 应用场景

| 场景 | 技术 | 说明 |
|------|------|------|
| **全局光照** | VCT | 高质量间接光 |
| **反射** | 体素反射 | 近似反射 |
| **遮挡** | 体素AO | 环境遮蔽 |
| **碰撞检测** | 体素碰撞 | 物理模拟 |

## 混合技术

### 光线追踪 + 体素

结合两者优势：

```
混合方案：
- 体素：快速近似GI
- 光线追踪：精确反射/阴影
- 结合：质量与性能平衡
```

### 光栅化 + 光线追踪

根据对象选择渲染方法：

```
主渲染：光栅化（快速）
反射：光线追踪（质量）
阴影：光线追踪（软阴影）
GI：路径追踪（可选）
```
