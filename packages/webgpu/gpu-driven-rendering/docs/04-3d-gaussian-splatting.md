## 概述

3D Gaussian Splatting (3DGS) 是一种新兴的渲染技术，使用 3D 高斯椭球体作为基本图元来表示和渲染场景。与传统的三角形网格不同，3DGS 通过数百万个带颜色、不透明度和协方差的高斯椭球体直接表示场景。

### 核心优势

| 优势 | 说明 |
|------|------|
| **照片级真实** | 从多视角照片学习，达到照片级质量 |
| **实时渲染** | 现代GPU可流畅渲染数百万高斯 |
| **高效表示** | 比点云/网格更紧凑的场景表示 |
| **连续表示** | 无多边形锯齿，无限细节 |
| **动态支持** | 新技术支持动态场景（4D渲染） |

### 设计目标

- **GPU驱动渲染**：利用计算着色器更新和排序
- **深度排序**：从前到后的正确渲染顺序
- **混合渲染集成**：与光栅化/SDF无缝结合
- **可扩展性**：支持静态和动态3DGS

## 数据结构

### Gaussian 3D 属性

```typescript
// 3D 高斯椭球体
interface Gaussian3D {
  position: vec3;      // 中心位置
  rotation: quat;      // 旋转（四元数）
  scale: vec3;         // 缩放（椭球轴长）
  opacity: float;      // 不透明度
  color: vec3;         // 颜色（SH 系数或 RGB）
}

// 存储布局（每个高斯 ~56 字节）
struct GaussianData {
  pos: vec3,           // 12 bytes
  opacity: float,      // 4 bytes
  scale: vec3,         // 12 bytes
  rotation: vec4,      // 16 bytes (quat)
  color: vec3          // 12 bytes
}
```

### 协方差矩阵

高斯椭球体由 3x3 协方差矩阵 Σ 定义：

```
协方差矩阵组成：
Σ = R S Sᵀ Rᵀ

其中：
- R：旋转矩阵（四元数转换）
- S：缩放对角矩阵
- Σ：3x3 协方差矩阵
```

## 渲染流程

```
┌─────────────────────────────────────────────────────────────┐
│              3D Gaussian Splatting 渲染流程                   │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  1. 高斯更新（计算着色器，可选）                              │
│     ├─ 动态场景：位置/旋转/缩放更新                          │
│     └─ 静态场景：跳过                                        │
│                                                              │
│  2. 视锥剔除（计算着色器）                                   │
│     ├─ 计算屏幕空间投影边界                                  │
│     └─ 剔除屏幕外高斯                                        │
│                                                              │
│  3. 深度排序（Bitonic Sort）                                 │
│     └─ 按相机距离从远到近排序                                │
│                                                              │
│  4. 渲染（从前到后，Alpha Blending）                         │
│     ├─ 顶点着色器：计算 2D 投影位置和大小                     │
│     ├─ 几何着色器：生成四边形                                │
│     ├─ 片段着色器：计算高斯密度和颜色                        │
│     └─ Alpha Blending 累积颜色                               │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### 顶点着色器

**任务**：计算屏幕空间投影和 2D 协方差

```wgsl

// 输出：屏幕位置、投影协方差、颜色

// 1. 提取高斯属性（位置、旋转、缩放）
// 2. 计算 View 和 Projection 变换
// 3. 计算 3D 协方差矩阵
// 4. 投影到 2D 屏幕空间
// 5. 输出到几何着色器
```

### 几何着色器

**任务**：生成屏幕对齐四边形

```wgsl
// 根据投影协方差的特征值
// 生成覆盖高斯主要区域的四边形
// 输出四个顶点到片段着色器
```

### 片段着色器

**任务**：渲染高斯密度

```wgsl
// 1. 计算像素到高斯中心的距离
// 2. 使用投影协方差计算高斯密度
//    density = exp(-0.5 * (x - μ)ᵀ Σ⁻¹ (x - μ))
// 3. 乘以颜色和不透明度
// 4. 输出用于 Alpha Blending
```

## 混合渲染集成

### 在混合渲染流程中的位置

```
Pass 8: 3D Gaussian Splatting
├─ 读取深度缓冲（用于协调）
├─ 从前到后渲染高斯
├─ Alpha Blending 累积
└─ 不写入深度（或写入后处理）

协调方式：
• 与光栅化几何：深度协调，避免 Z-fighting
• 与 SDF：3DGS 用于真实场景，SDF 用于背景
• 与透明物体：统一排序流程
```

### 深度协调

| 场景 | 深度处理 | 说明 |
|------|----------|------|
| **纯 3DGS** | 不写入深度 | 前到后渲染，Alpha 累积 |
| **混合光栅化** | 读取深度 | 协调遮挡关系 |
| **混合透明物体** | 统一排序 | 一并从后到前渲染 |

## 优化策略

### LOD 策略

| 距离 | 策略 | 性能提升 |
|------|------|----------|
| **近** | 原始高斯 | - |
| **中** | 合并相似高斯 | ~30% |
| **远** | 降低密度或使用网格 | ~50% |

### 自适应密度

```
视觉敏感区域（图像中心、高梯度）：
→ 保留更多高斯

非敏感区域（图像边缘、低梯度）：
→ 减少高斯数量
```

### 分块渲染

```
空间分块：
• 将场景划分为 32x32 或 64x64 块
• 空块跳过渲染
• 视锥外块剔除
```

### 整数渲染

```
性能优化：
• 半分辨率渲染
• 后处理上采样
• 时域抗锯齿补充
```
