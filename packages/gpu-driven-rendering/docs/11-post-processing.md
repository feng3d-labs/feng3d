## 概述

后处理管线在主渲染完成后对图像进行一系列处理，包括色调映射、抗锯齿、泛光、景深等效果，是提升画面质量的关键环节。

### 设计目标

- **模块化**：每个后处理效果独立可配置
- **可组合**：支持动态添加/移除效果
- **高性能**：复用中间缓冲，减少内存分配
- **GPU驱动**：命令生成和调度全GPU驱动

## 核心后处理效果

### Tone Mapping（色调映射）

将HDR（高动态范围）颜色映射到LDR（低动态范围）显示设备。

#### 目的

- 模拟人眼对亮度的适应
- 保留高光细节
- 防止颜色过饱和

#### 算法

| 算法 | 特点 | 适用场景 |
|------|------|----------|
| **Linear** | 简单裁剪 | 调试 |
| **Reinhard** | 自适应，自然 | 通用 |
| **Filmic** | 电影感，细节丰富 | 电影风格 |
| **ACES** | 电影工业标准 | 高质量 |
| **Exposure** | 手动曝光控制 | 摄影风格 |

#### ACES Tone Mapping

电影艺术与科学学院标准，提供最自然的HDR到LDR转换。

特点：
- 保留阴影细节
- 自然的高光过渡
- 饱和度保持
- 行业标准

---

### 抗锯齿（Anti-Aliasing）

消除渲染产生的锯齿边缘。

#### 类型对比

| 类型 | 质量 | 性能 | MSAA兼容 | 适用场景 |
|------|------|------|----------|----------|
| **MSAA** | 高 | 中 | N/A | 前向渲染 |
| **FXAA** | 中 | 极高 | ✅ | 性能优先 |
| **TAA** | 极高 | 中 | ❌ | 质量优先 |
| **SMAA** | 高 | 高 | ✅ | 平衡 |

#### FXAA（Fast Approximate Anti-Aliasing）

快速近似抗锯齿，后期处理实现。

特点：
- 性能开销极低
- 实现简单
- 可能模糊细节
- 适合动态场景

#### TAA（Temporal Anti-Aliasing）

时序抗锯齿，利用历史帧信息。

流程：
1. 当前帧和上一帧对齐
2. 混合像素颜色
3. 修复色差（ghosting）
4. 锐化细节

特点：
- 质量最高
- 需要运动向量
- 可能产生ghosting
- 适合静态场景

---

### Bloom / Glow（泛光）

模拟高光溢出效果，增强视觉冲击力。

#### 流程

```
高亮提取 → 高斯模糊 → 混合叠加
```

#### 参数

| 参数 | 说明 | 范围 |
|------|------|------|
| Threshold | 高亮提取阈值 | 0.5 - 2.0 |
| Intensity | 泛光强度 | 0.0 - 2.0 |
| Radius | 模糊半径 | 1 - 10 |
| Color | 泛光色调 | RGB |

#### 类型

| 类型 | 特点 |
|------|------|
| **Standard Bloom** | 标准泛光 |
| **Lens Dirt** | 镜头污迹效果 |
| **Anamorphic** | 宽银幕镜头效果 |
| **Glow** | 简单辉光 |

---

### Depth of Field（景深）

模拟相机对焦效果，模糊前景和背景。

#### 流程

```
CoC计算 → 前景模糊 → 背景模糊 → 混合
```

#### 参数

| 参数 | 说明 |
|------|------|
| Focus Distance | 对焦距离 |
| Focus Range | 对焦范围 |
| Near Blur | 前景模糊强度 |
| Far Blur | 背景模糊强度 |

#### 类型

| 类型 | 特点 |
|------|------|
| **Simple DoF** | 简单高斯模糊 |
| **Bokeh DoF** | 散景效果 |
| **Ring DoF** | 环形光斑效果 |

## 其他后处理效果

### Color Grading（色彩分级）

调整整体色调风格。

#### 技术

- **LUT（Look-Up Table）**：预定义颜色映射表
- **ASC CDL**：色彩决策列表（Slope/Offset/Power）
- **HSL调整**：色相/饱和度/亮度

### Motion Blur（运动模糊）

模拟快速运动时的动态模糊。

#### 实现

- **Per-Object**：基于物体速度
- **Per-Pixel**：基于运动向量
- **Camera**：基于相机运动

### Ambient Occlusion（环境光遮蔽）

模拟间接光照遮蔽效果。

#### 类型

| 类型 | 质量 | 性能 |
|------|------|------|
| **SSAO** | 中 | 高 |
| **HBAO** | 高 | 中 |
| **GTAO** | 极高 | 中 |

### Chromatic Aberration（色差）

模拟镜头色差效果，增强真实感。

### Vignette（暗角）

图像边缘变暗，聚焦视线中心。

## 后处理管线架构

### 管线配置

```typescript
// 后处理效果配置
interface PostProcessConfig {
  // 抗锯齿
  fxaa?: { enabled: boolean };
  taa?: { enabled: boolean; feedbackMin: number; feedbackMax: number };

  // 泛光
  bloom?: {
    enabled: boolean;
    threshold: number;
    intensity: number;
    radius: number;
  };

  // 色调映射
  toneMapping: {
    type: 'linear' | 'reinhard' | 'filmic' | 'aces';
    exposure: number;
  };

  // 景深
  dof?: {
    enabled: boolean;
    focusDistance: number;
    focusRange: number;
  };

  // 其他
  colorGrading?: { enabled: boolean; lut?: Texture };
  motionBlur?: { enabled: boolean;强度: number };
  vignette?: { enabled: boolean; intensity: number };
}
```

### 渲染目标管理

```
Ping-Pong缓冲策略：
┌─────────────────────────────────────────────────────────────┐
│                                                              │
│  RT0 ────────> RT1 ────────> RT2 ────────> RT0              │
│   (输入)       (效果1)       (效果2)       (循环)             │
│                                                              │
│  优点：减少缓冲数量                                           │
│  缺点：需要合理安排执行顺序                                   │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### GPU驱动集成

```
计算着色器任务：
1. 确定启用的后处理效果
2. 生成每个效果的渲染命令
3. 管理渲染目标切换
4. 执行最终输出
```

## 性能优化

### 分辨率缩放

对性能要求高的效果降低分辨率：

| 效果 | 推荐分辨率 |
|------|------------|
| Bloom | 1/2 或 1/4 |
| DoF | 1/2 |
| Motion Blur | 全分辨率 |
| Tone Mapping | 全分辨率 |

### 异步计算

使用独立计算队列执行后处理：

```
队列0：主渲染
队列1：后处理（并行执行）
```

### 效果合并

将兼容的效果合并到单个Pass：

- Tone Mapping + Gamma Correction
- Bloom + Lens Dirt
- Color Grading + Vignette
