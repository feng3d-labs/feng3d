## 概述

阴影系统为场景提供高质量的阴影渲染，支持 directional light、point light、spot light 等多种光源类型。

### 设计目标

- **GPU驱动**：阴影渲染命令由GPU生成，CPU仅触发
- **高质量**：支持PCF、PCSS等软阴影算法
- **高性能**：CSM级联优化，按需更新
- **多路径兼容**：与前向/延迟渲染无缝集成

## 阴影类型

| 类型 | 适用光源 | 算法 | 质量 | 性能 |
|------|----------|------|------|------|
| **Shadow Mapping** | Directional/Spot | 深度比较 | 中 | 高 |
| **CSM** | Directional | 级联阴影贴图 | 高 | 中 |
| **PCF** | 通用 | 百分比接近过滤 | 高 | 中 |
| **PCSS** | 通用 | 百分比接近软阴影 | 极高 | 低 |
| **VSM** | 通用 | 阴影贴图过滤 | 高 | 中 |
| **ESM** | 通用 | 指数阴影贴图 | 高 | 中 |

## 阴影贴图 (Shadow Mapping)

### 原理

渲染光源视角的深度图，然后在主渲染Pass中比较深度来判断阴影。

### 渲染流程

```
┌─────────────────────────────────────────────────────────────┐
│                    阴影贴图渲染流程                           │
├─────────────────────────────────────────────────────────────┤
│  1. 光源视角剔除               （GPU Culling from light）     │
│  2. 阴影深度Pass               （渲染光源深度）                │
│  3. 主渲染Pass                 （深度比较，计算阴影）          │
└─────────────────────────────────────────────────────────────┘
```

### 核心概念

- **Light Space Transform**：将世界坐标转换到光源空间
- **Depth Comparison**：比较像素深度与阴影贴图深度
- **Bias**：防止阴影失真（ acne/peter-panning）

## 级联阴影贴图 (CSM)

### 原理

为 directional light 创建多个深度贴图（级联），每个级联覆盖不同距离范围，近处高精度，远处低精度。

### 级联划分

```
相机视锥体划分：
┌─────────────────────────────────────────────────────────────┐
│                    近处级联                                  │
│  ┌────────┐  ┌────────┐  ┌────────┐  ┌────────┐             │
│  │Cascade0│→ │Cascade1│→ │Cascade2│→ │Cascade3│             │
│  │高精度  │  │中高精度│  │中精度  │  │低精度  │             │
│  └────────┘  └────────┘  └────────┘  └────────┘             │
│   0-10m      10-30m      30-80m      80-200m                 │
└─────────────────────────────────────────────────────────────┘
```

### 级联配置

| 参数 | 说明 | 推荐值 |
|------|------|--------|
| 级联数量 | 分层数量 | 4 |
| 分割方案 | 线性/对数/手动 | 对数+线性混合 |
| 分辨率 | 每级联分辨率 | 1024x1024 |
| 更新频率 | 每帧更新策略 | 近处每帧，远处隔帧 |

### 优势

- 近处阴影清晰
- 远处覆盖范围大
- 精度分配合理
- 内存占用可控

## 软阴影算法

### PCF (Percentage Closer Filtering)

**原理**：在阴影比较时采样邻域深度，计算阴影比例。

**特点**：
- 简单高效
- 边缘柔和
- 固定模糊半径
- 适合大多数场景

### PCSS (Percentage Closer Soft Shadows)

**原理**：根据遮挡物距离动态调整采样半径，模拟真实软阴影。

**流程**：
1. **Blocker Search**：查找平均遮挡物距离
2. **Penumbra Estimation**：计算半影半径
3. **PCF Filtering**：基于动态半径采样

**特点**：
- 物理准确
- 动态软阴影
- 性能开销大
- 适合高质量场景

### VSM (Variance Shadow Maps)

**原理**：存储深度的一阶矩（M1）和二阶矩（M2），用切比雪夫不等式估算阴影概率。

**特点**：
- 无需深度偏移
- 支持过滤
- 可能光泄漏
- 内存占用2x

## GPU驱动阴影渲染

### 命令生成

阴影渲染命令由GPU计算着色器生成，与主渲染共享剔除结果。

### 数据结构

- **ShadowCommandBuffer**：阴影绘制命令缓冲
- **CascadeInfo**：级联信息（范围、矩阵）
- **ShadowAtlas**：阴影贴图集，高效存储多光源阴影

### 渲染流程

```
┌─────────────────────────────────────────────────────────────┐
│                GPU驱动阴影渲染流程                            │
├─────────────────────────────────────────────────────────────┤
│  计算着色器：                                                 │
│  1. 读取剔除结果              （复用主渲染剔除数据）           │
│  2. 按光源分组物体              （生成每光源的绘制列表）        │
│  3. 按级联分组物体              （CSM按级联分桶）              │
│  4. 生成间接绘制命令            （写入ShadowCommandBuffer）    │
│                                                              │
│  渲染通道：                                                   │
│  5. Shadow Depth Pass          （multiDrawIndexedIndirect）   │
│  6. 主渲染Pass                 （读取阴影贴图）                │
└─────────────────────────────────────────────────────────────┘
```

## 光源类型支持

### Directional Light（方向光）

- **算法**：Shadow Mapping + CSM
- **级联**：4级联可配置
- **更新**：近处每帧，远处隔帧
- **质量**：PCSS软阴影

### Point Light（点光源）

- **算法**：Cube Shadow Mapping
- **面数**：6面（立方体贴图）
- **优化**：单Pass渲染或6个Pass
- **质量**：PCF软阴影

### Spot Light（聚光灯）

- **算法**：2D Shadow Mapping
- **分辨率**：512-2048可配置
- **优化**：视锥体外剔除
- **质量**：PCF软阴影

## 性能优化

### 级联更新策略

| 级联 | 更新频率 | 说明 |
|------|----------|------|
| Cascade0 | 每帧 | 近处，需要高精度 |
| Cascade1 | 每帧 | 中近，相机移动频繁影响 |
| Cascade2 | 隔帧 | 中远，变化较慢 |
| Cascade3 | 每3帧 | 远处，变化最慢 |

### 阴影贴图集

将多个光源的阴影贴图打包到一个大纹理中，减少绑定切换。

### 精度优化

- **Depth Format**：使用DEPTH24_PLUS或DEPTH32_FLOAT
- **Bias Adjustment**：根据法线调整深度偏移
- **Normal Offset**：沿法线偏移深度，减少失真

## 与渲染路径集成

### 前向渲染

- 着色器中直接采样阴影贴图
- 每个光源计算阴影因子
- 叠加到最终光照

### 延迟渲染

- 光照Pass中采样阴影贴图
- 可在G-Buffer后单独渲染
- 支持更多光源

### Forward+

- 光照列表中包含阴影贴图索引
- 瓦片/聚类级别计算阴影
- 批量阴影计算
